# Weather101 🌤️

A vanilla JavaScript weather application built as a challenge from [roadmap.sh](https://roadmap.sh). This is the **first public version** of this project.

## 🎯 Project Goal

The goal of this project was to complete a roadmap.sh challenge to build a fully functional weather application using **only vanilla HTML, CSS, and JavaScript** — no frameworks, no libraries, just pure web technologies.

This project serves as both a learning exercise and a demonstration of what can be accomplished with vanilla web development practices.

## ✨ Features

- **Real-time Weather Data**: Fetch current weather information
- **Responsive Design**: Works seamlessly across devices
- **Pure Vanilla Frontend**: No external frameworks or dependencies
- **Clean UI**: Intuitive and user-friendly interface

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** (49.8%) - Styling and layout
- **JavaScript** (38.1%) - Core functionality and interactivity

## 📦 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or dependencies required

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/GrassInSuit/Weather101.git
   cd Weather101
   ```

2. **Open the application**
   - Open `index.html` directly in your browser
   - Or use a local server:
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js (if installed)
     npx http-server
     ```

3. **Visit in your browser**
   - Navigate to `http://localhost:8000` (or your chosen port)

## 🚀 Usage

1. Enter a city name or location
2. The app will fetch and display current weather information
3. View temperature, conditions, and other relevant data
